# Character artwork

Existing official character assets selected for this personal birthday invitation on November 6, 2026. The assets are copyrighted character artwork; no claim of original authorship or open licensing is made.

- `spider-man.webp`: [Marvel Spider-Man character page](https://www.marvel.com/characters/spider-man-peter-parker/); [source JPEG](https://terrigen-cdn-dev.marvel.com/content/prod/1x/spidey02_ons_mas_dsk_01.jpg), 1920 × 640. Encoded as WebP; the browser positions the character inside the panel.
- `optimus-prime.webp`: [Hasbro Optimus Prime G1 biography](https://transformers-bios.hasbro.com/en-us/optimus-prime-g1-autobot); [source GIF](https://assets-us-01.kc-usercontent.com/500e0a65-283d-00ef-33b2-7f1f20488fe2/a6417570-732f-4c5d-a511-a29b43e36ca0/optimusprime.gif), 850 × 850. The first frame is encoded as a static WebP to avoid automatic motion and the 4.6 MB animated download.

A built-in image-generation attempt for a combined character illustration was rejected by the tool, so no generated artwork is included.
